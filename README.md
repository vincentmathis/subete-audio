# Subete audio packs

Downloadable Japanese sentence audio for the Subete app. Each ZIP contains a
`manifest.json` mapping sentence text to an `.m4a` clip, plus the clips.

Generated offline with [Supertonic 3](https://huggingface.co/Supertone/supertonic-3)
(Supertone, OpenRAIL-M) through [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx)
(Apache-2.0). No human recording is cloned and no learner data is involved.

Sentence text comes from the Subete content database (JMdict and original
grammar). The audio itself is synthetic and may be used with the app.
